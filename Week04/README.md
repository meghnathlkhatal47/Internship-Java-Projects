Library Management System (Refactored Version)

Project Description:
This is a Java command-line application developed to manage a library's book inventory. The application performs CRUD (Create, Read, Update, Delete) operations using Java Collections Framework (ArrayList).

Features:
1. Add Book
2. View All Books
3. Update Book Information
4. Delete Book
5. Exit Application

Book Attributes:
- Book ID
- Title
- Author
- ISBN
- Publication Year

Refactoring Improvements:
- Reduced duplicate code using reusable methods.
- Improved readability and maintainability.
- Better exception handling.
- Applied DRY (Don't Repeat Yourself) principle.
- Modularized application logic.

Requirements:
- Java JDK 8 or above

Compile:
javac *.java

Run:
java Main
